# CEIR Checker Pro

IMEI Scanner for CEIR Status Check

## Features
- OCR + Barcode IMEI Scanner
- CEIR API Integration
- Paid/Unpaid + Device Info
- History + Cloud Sync (Supabase)

## Tech Stack
- Native Android (Kotlin)
- Supabase (Cloud)
- WebView + content.js
- GitHub Actions (Auto Build APK)

## Build
Push တိုင်း GitHub Actions မှာ APK Auto Build ဖြစ်တယ်။
